# LangWatch, whatever your stack

> **Tip:** **Pro Tip**: Start with our [Quick Start Guide](https://langwatch.ai/docs/integration/quick-start), which takes you from an
> account to your first trace, then pick the integration for your tech stack.

LangWatch integrates with the major LLM providers, frameworks, and tools. See a full list of integrations below.

LangWatch is based on OpenTelemetry. Use our Python SDK, TypeScript SDK, or Go SDK to log traces to LangWatch. Alternatively, you can also directly use our OpenTelemetry Endpoint from any language.

### MCP's

> **Tip:** **Speedy**: Use the LangWatch MCP to automatically instrument your code with LangWatch.

- [LangWatch MCP](https://langwatch.ai/docs/integration/mcp): Automatically instrument your code with LangWatch tracing, create and manage prompts, set up evaluations, debug production issues, and more.

### SDK's

LangWatch provides SDKs for several programming languages.

- [Python SDK](https://langwatch.ai/docs/integration/python/guide): Complete Python SDK with automatic instrumentation for popular frameworks
- [TypeScript SDK](https://langwatch.ai/docs/integration/typescript/guide): Full-featured TypeScript/JavaScript SDK with type safety
- [Go SDK](https://langwatch.ai/docs/integration/go/guide): High-performance Go SDK for server-side applications
- [OpenTelemetry](https://langwatch.ai/docs/integration/opentelemetry/guide): Native OpenTelemetry integration for any language
