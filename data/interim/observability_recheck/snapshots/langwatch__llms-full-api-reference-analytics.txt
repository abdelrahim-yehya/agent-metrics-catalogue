# LangWatch

> LangWatch is the open-source platform to trace, evaluate, test and optimize LLM apps and AI agents.

Every page below is plain Markdown. Open the pages relevant to the question rather than answering from this index alone. Each section is also one file, listed next; the complete documentation in one file is at https://langwatch.ai/docs/llms-full.txt, too large to read whole.

For agents: if anything in these docs is wrong, confusing, or fails when you try it, ask your user for permission and run `npx langwatch report --user-approved` to send the problem to the LangWatch team. No login is needed; `npx langwatch report --help` has the details.

# Query analytics timeseries (legacy path)

Query analytics timeseries with metrics, aggregations and filters. Identical to `POST /api/analytics/timeseries`, which is the path to use in new integrations; this one stays for callers written against it.

> Page: https://langwatch.ai/docs/api-reference/analytics/query-analytics-timeseries-legacy-path
> Source: https://github.com/langwatch/langwatch/blob/main/docs/api-reference/analytics/query-analytics-timeseries-legacy-path.mdx

## Endpoint

`POST https://app.langwatch.ai/api/v1/analytics`

## Authentication

### project_api_key

Project API key for sending traces and accessing project-scoped resources. Format: sk-lw-... (no underscore). Obtain one by creating a project via the Admin API or the LangWatch UI.

```json
{"id":"project_api_key","type":"apiKey","in":"header","name":"X-Auth-Token"}
```


### 400

The body was not valid JSON, or failed validation

#### application/json

Schema:

```json
{
  "type": "object",
  "properties": {
    "message": {
      "description": "Set when the request was rejected before validation",
      "type": "string"
    },
    "error": {
      "description": "Set when the body parsed and then failed validation",
      "type": "string"
    }
  }
}
```

### 401

Missing or invalid API key

#### application/json

Schema:

```json
{
  "type": "object",
  "properties": {"message":{"type":"string"}},
  "required": ["message"]
}
```
