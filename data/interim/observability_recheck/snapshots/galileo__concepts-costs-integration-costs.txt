# Integration Costs

The **Integration Costs** page allows organization users to track project costs for [decision model](https://docs.galileo.ai/concepts/metrics/custom-metrics/custom-decision-model-metrics.md) and [LLM-as-a-judge](https://docs.galileo.ai/concepts/metrics/how-llm-as-judge-metrics-are-calculated.md) metrics.

In the Galileo UI, select your user profile and select **Integration costs** to access the page.

![Integration Costs](https://mintcdn.com/v2galileo/bZTy0tPZ20JWcXTN/images/console-ui/integration-costs.png?fit=max\&auto=format\&n=bZTy0tPZ20JWcXTN\&q=85\&s=3d72f506b920de8a1ae444642e5ce5f7)

The Integration Costs page is visible to all users in the organization as a read-only view.
