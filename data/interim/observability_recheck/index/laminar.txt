- [Ingest OpenTelemetry traces](https://laminar.sh/docs/api-reference/ingestion/ingest-opentelemetry-traces.md): Accepts an OTLP ExportTraceServiceRequest encoded as protobuf or OTLP JSON.
- [Create spans](https://laminar.sh/docs/api-reference/ingestion/create-spans.md): Ingests a batch of spans using Laminar's JSON span format.
- [Ingest OpenTelemetry logs](https://laminar.sh/docs/api-reference/ingestion/ingest-opentelemetry-logs.md): Accepts an OTLP ExportLogsServiceRequest encoded as protobuf. JSON-encoded OTLP is not accepted. This endpoint is in beta: ingested logs are stored in the `logs` table and can only be queried with SQL. They are not shown anywhere in the Laminar UI, and Signals do not read them when analyzing traces.
- [Add labeling queue items](https://laminar.sh/docs/api-reference/labeling-queues/add-labeling-queue-items.md): Adds items to a labeling queue, optionally deduplicating them with idempotency keys.
- [Query project data](https://laminar.sh/docs/api-reference/sql/query-project-data.md): Executes a validated, read-only SQL query scoped to the authenticated project.
- [Get the current project](https://laminar.sh/docs/api-reference/projects/get-the-current-project.md): Returns the project ID associated with the supplied API key.
- [List datasets](https://laminar.sh/docs/api-reference/datasets/list-datasets.md): Lists project datasets, optionally filtered by dataset ID or name.
- [Create a dataset](https://laminar.sh/docs/api-reference/datasets/create-a-dataset.md): Creates an empty dataset. Dataset names do not need to be unique.
- [Get a dataset](https://laminar.sh/docs/api-reference/datasets/get-a-dataset.md): Returns a dataset by its canonical ID.
- [Delete a dataset](https://laminar.sh/docs/api-reference/datasets/delete-a-dataset.md): Deletes a dataset and its datapoints.
- [Update a dataset](https://laminar.sh/docs/api-reference/datasets/update-a-dataset.md): Renames a dataset. Dataset names do not need to be unique.
- [List dataset datapoints](https://laminar.sh/docs/api-reference/datasets/list-dataset-datapoints.md): Returns a paginated page of datapoints from a dataset identified by ID or name.
- [Create dataset datapoints](https://laminar.sh/docs/api-reference/datasets/create-dataset-datapoints.md): Adds datapoints to a dataset and can optionally create the dataset when identified by name.
- [List Signals](https://laminar.sh/docs/api-reference/signals/list-signals.md): Lists Signals in the project, optionally filtering by a name substring.
- [Create a Signal](https://laminar.sh/docs/api-reference/signals/create-a-signal.md): Creates a Signal with the first server-managed configuration version.
- [Get a Signal](https://laminar.sh/docs/api-reference/signals/get-a-signal.md): Returns a Signal in the authenticated project.
- [Delete a Signal](https://laminar.sh/docs/api-reference/signals/delete-a-signal.md): Deletes a Signal and returns its final state.
- [Update a Signal](https://laminar.sh/docs/api-reference/signals/update-a-signal.md): Updates a Signal. An update that changes the effective Signal configuration increments its server-managed version.
- [List LLM profiles](https://laminar.sh/docs/api-reference/llm-profiles/list-llm-profiles.md): Lists every LLM profile in the authenticated project's workspace.
- [Create an LLM profile](https://laminar.sh/docs/api-reference/llm-profiles/create-an-llm-profile.md): Creates an LLM profile in the authenticated project's workspace.
- [Get an LLM profile](https://laminar.sh/docs/api-reference/llm-profiles/get-an-llm-profile.md): Returns an LLM profile from the authenticated project's workspace. Secret values are masked.
- [Delete an LLM profile](https://laminar.sh/docs/api-reference/llm-profiles/delete-an-llm-profile.md): Deletes an LLM profile and returns its final state.
- [Update an LLM profile](https://laminar.sh/docs/api-reference/llm-profiles/update-an-llm-profile.md): Updates an LLM profile. Omitted fields retain their stored values, `models` replaces the complete model list, a supplied `config` replaces the whole stored config object, and supplied secrets are merged with stored secrets.
- [Create an evaluation](https://laminar.sh/docs/api-reference/evaluations/create-an-evaluation.md): Creates an evaluation run, generating a name when none is supplied.
- [Update an evaluation](https://laminar.sh/docs/api-reference/evaluations/update-an-evaluation.md): Updates an evaluation's name and/or metadata; omitted fields remain unchanged.
- [Add evaluation datapoints](https://laminar.sh/docs/api-reference/evaluations/add-evaluation-datapoints.md): Adds result datapoints to an evaluation run.
- [Update an evaluation datapoint](https://laminar.sh/docs/api-reference/evaluations/update-an-evaluation-datapoint.md): Updates a datapoint's executor output, scores, and optional trace association.
